# Brand

## Name

Blindpot — "blind" (you can't see the numbers) + "pot" (the prize pool).
Checked clean against existing crypto projects. Deliberately not using
"veil / cloak / shroud" language, to avoid association with privacy-coin /
mixer branding — a different category with very different regulatory optics
than a savings product.

## Mark

A ring (the pot / coin / porthole) containing three redaction bars, two
silver and one brass. Logo asset: `public/logo.png`. Design system token specifications:
`bureau_document_system/DESIGN.md`.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#0F0F12` / `#12131A` | text, borders, dark backgrounds |
| Ledger Silver / Paper | `#EEF1F7` / `#EDEBE3` | wordmark, redaction bars, page background |
| Prize Brass | `#C9A15A` | reserved exclusively for real money about to become visible — never decorative |
| Stamp Red | `#C1432E` | live/urgent indicators, stamp badges only |
| Redacted / Muted Gray | `#B7B3A6` / `#8A8F9E` | sealed-state bars, supporting text |

## Type

- **IBM Plex Mono** — logotype, headlines (caps, tight tracking), every
  numeric value (tabular figures, always)
- **IBM Plex Sans** — body copy, labels, sentence case

## UI direction

Raw print/document brutalism — redacted dossier, ledger paper, stamps. Not
playful neubrutalist SaaS (pastel blocks, comic shadows) — that's its own
generic cluster now. Source design specifications:
`bureau_document_system/DESIGN.md`.

## Signature interaction

Every monetary value renders as redaction bars by default. Decrypting
replaces them with real brass digits plus a rotated "DECRYPTED" stamp. This
is the one interaction pattern the whole product hangs on — reuse it
everywhere a number appears (balance, prize, pool size where applicable).
Never invent a second pattern for the same idea.
